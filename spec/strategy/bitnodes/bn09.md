# BN9 — Hacktocracy

> *"Hacknet Unleashed"* · theme: [`hacknet`](../features/hacknet.md)

**In-node:** Hacknet Nodes are replaced by **Hacknet Servers**, which mint
**hashes** instead of money
(`sim/vendor/bitburner/src/Hacknet/formulas/HacknetServers.ts:5-18`) and join the
script fleet as ordinary RAM hosts, counted in fleet RAM but excluded from the
purchased-server aggregate (`game/lib/probes/local.ts:47-53`). Caps are 20
servers, level 300, 8192 GB, 128 cores, cache 15
(`sim/vendor/bitburner/src/Hacknet/data/Constants.ts:33-52`). Entering the node
grants one server at level 100, 10 cores, cache 5 — at any SF9 level, unless
`bitNodeOptions.disableHacknetServer` is set (`src/Prestige.ts`
`prestigeSourceFile()`, upstream commit `3162fd2` pinned in
`sim/transcription-sources.ts:12`). The hash-spend menu is in
[`../features/hacknet.md`](../features/hacknet.md).

## SF9

| Level | Production | Costs | Grant |
|---|---|---|---|
| 1 | ×1.12 | ×0.88 | Hacknet Servers in every other BitNode |
| 2 | ×1.18 | ×0.82 | home RAM set to **128 GB** on BitNode entry |
| 3 | ×1.21 | ×0.79 | one Hacknet Server at level 100, 10 cores, cache 5 on entry |

Production is `hacknet_node_money`; the cost factor is `1 - mult/100` applied to
purchase, level, RAM and core costs, with `mult` = 12 / 18 / 21
(`sim/vendor/bitburner/src/SourceFile/applySourceFile.ts:134-148`).

The level-1 grant is the `canAccessBitNodeFeature(9)` half of
`hasHacknetServers()` (`src/Hacknet/HacknetHelpers.tsx`); the level-2 and level-3
grants fire in `prestigeSourceFile()`, i.e. on **entering a BitNode**, not on
installing augmentations — `prestigeAugmentation()` does not reference SF9
(`src/Prestige.ts`, commit `3162fd2`).

## Notes

- `CloudServerLimit` 0 with `HomeComputerRamCost` 5 leaves Hacknet Servers as the
  only purchasable RAM; the ceiling is 20 × 8192 GB.
- BN9 sets no `HacknetNodeMoney`, so hash production itself takes no node penalty.
- Hash rate carries a `1 - ramUsed/maxRam` factor (`HacknetServers.ts:15`), so
  every GB the fleet occupies costs hashes.
