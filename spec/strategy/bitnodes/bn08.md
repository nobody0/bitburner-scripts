# BN8 — Ghost of Wall Street

> *"Money never sleeps"* · theme: `stock`

**In-node:** start with **$250 000 000**, a WSE membership and TIX API access,
and the ability to short and place limit/stop orders.

## Multipliers vs BN1

The most surgical set in the game — almost everything is **zero**:

| Group | Changes |
|---|---|
| Income → 0 | `CompanyWorkMoney` · `CrimeMoney` · `HacknetNodeMoney` · `ManualHackMoney` · `CodingContractMoney` · `InfiltrationMoney` · `DarknetMoneyMultiplier` |
| Hacking | `ScriptHackMoney` 0.3 · **`ScriptHackMoneyGain` 0** |
| Features off | `CorporationValuation` 0 · `CorporationSoftcap` 0 · `CorporationDivisions` 0 · `BladeburnerRank` 0 · `GangSoftcap` 0 · `GangUniqueAugs` 0 · `StaneksGiftExtraSize` **−99** · `DarknetLabyrinthRewardsTheRedPill` 0 |
| Reset loop | `FavorToDonateToFaction` **0** → donations from **0 favor** |
| Fleet | `CloudServerSoftcap` 4 |
| Endgame | `WorldDaemonDifficulty` **unchanged** → hacking 3000 |

## Reading

- `ScriptHackMoney` 0.3 **and** `ScriptHackMoneyGain` 0 together: the server
  loses money and you gain none. Hacking survives only as **experience** and as
  **stock manipulation** — hacking drives a symbol down, growing drives it up.
  That is the node's actual mechanic.
- The finish line is BN1's, but every route to it except the market is closed.
- `FavorToDonateToFaction` 0 means all rep is buyable from turn one, so the
  reset loop collapses to "trade, donate, buy augs".

## For our code

- `stock` needs a real trading strategy — 4S-aware, short-aware — plus
  **hack/grow-as-manipulation coordination with `hacking`**. That is a genuine
  contention case the arbiter does not model: the farm wants max $/GB/sec, BN8
  wants the farm to move one symbol.
- Anything assuming hacked money arrives must tolerate `ScriptHackMoneyGain: 0`
  without reporting the farm as broken.
