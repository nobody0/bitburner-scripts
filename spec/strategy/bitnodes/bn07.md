# BN7 — Bladeburners 2079

> *"More human than humans"* · theme: [`bladeburner`](../features/bladeburner.md)

**In-node:** the same **Bladeburner** division as BN6 — one feature hosted by two
nodes. The ns API works in either: "you have to be employed in the Bladeburner
division and be in BitNode 6/7 or have Source-File 6/7"
(`types/NetscriptDefinitions.d.ts:3433`). BN7 is the harder of the two, and the
only node of the pair that touches the Bladeburner multipliers themselves.

## Multipliers vs BN1

Identical to BN6 except where marked **new** or *(BN6: …)*
(`sim/vendor/bitburner/src/BitNode/BitNodeMults.ts:166-206`).

| Group | Changes |
|---|---|
| Hacking | `HackingLevelMultiplier` 0.35 · `HackExpGain` 0.25 · `ScriptHackMoney` **0.5** *(BN6: 0.75)* |
| Servers | `ServerMaxMoney` 0.2 · `ServerStartingMoney` 0.5 · `ServerStartingSecurity` 1.5 · `CloudServerSoftcap` 2 |
| Income | `HacknetNodeMoney` 0.2 · `CompanyWorkMoney` 0.5 · `CrimeMoney` 0.75 · `InfiltrationMoney` 0.75 |
| Bladeburner | `BladeburnerRank` **0.6** (new) · `BladeburnerSkillCost` **2** (new) |
| Reset loop | `AugmentationMoneyCost` **3** (new) · `DaedalusAugsRequirement` 35 |
| Market | `FourSigmaMarketDataCost` **2** (new) · `FourSigmaMarketDataApiCost` **2** (new) |
| Other features | `CorporationValuation` 0.2 · `CorporationSoftcap` 0.9 · `CorporationDivisions` 0.8 · `GangSoftcap` 0.7 · `GangUniqueAugs` 0.2 · `StaneksGiftPowerMultiplier` 0.9 *(BN6: 0.5)* · `StaneksGiftExtraSize` −1 *(BN6: +2)* |
| Endgame | `WorldDaemonDifficulty` 2 → hacking **6000** (base 3000, `worldDaemonSkill` in `shared/features/bitnode.ts:374-378`) |

Those five new fields and three changed values are the entire difference: BN7
changes 25 fields against BN1, BN6 changes 20, and no BN6 field is absent here.

## SF7

Per level, `bladeburner_max_stamina`, `bladeburner_stamina_gain`,
`bladeburner_analysis` and `bladeburner_success_chance` gain a cumulative
+8% / +12% / +14%
(`sim/vendor/bitburner/src/SourceFile/applySourceFile.ts:111-123`).

**Level 3 additionally grants The Blade's Simulacrum immediately on joining the
division** (`types/NetscriptDefinitions.d.ts:3966`). Because that is an
augmentation, it fixes the order in which Stanek's Gift must be taken — see
[`../features/stanek.md`](../features/stanek.md) and
[`../features/bladeburner.md`](../features/bladeburner.md).
