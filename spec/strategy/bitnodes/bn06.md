# BN6 — Bladeburners

> *"Like Tears in Rain"* · theme: [`bladeburner`](../features/bladeburner.md)

**In-node:** the **Bladeburner** division at the NSA, "which provides a new
mechanic for progression" (`src/BitNode/BitNode.tsx:211-231`). It carries its
own faction, invited at `RankNeededForFaction` 25
(`sim/vendor/bitburner/src/Bladeburner/data/Constants.ts:43`), and its own
augmentation pool.

**The ns API is available here.** `src/NetscriptFunctions/Bladeburner.ts:35`
gates on `canAccessBitNodeFeature(7) || canAccessBitNodeFeature(6)`, as does
`canAccessBladeburner()`
(`src/PersonObjects/Player/PlayerObjectBladeburnerMethods.ts:6-8`) — BN6 or SF6
is sufficient. Older notes claiming SF7 is required for the API are wrong.

Twenty fields, the complete set that differs from BN1
(`sim/vendor/bitburner/src/BitNode/BitNodeMultipliers.ts` `case 6`, via
`bitNodeMultipliers(6, 0)` in `shared/features/bitnode.ts`).

## SF6

Access the Bladeburner division in other BitNodes, and raise **both the level
and the experience gain rate** of all four combat stats — strength, defense,
dexterity, agility — by **+8% / 12% / 14%**
(`sim/vendor/bitburner/src/SourceFile/applySourceFile.ts` `case 6`;
`src/BitNode/BitNode.tsx:232-243`). Charisma is not affected.

## Notes

- BN6 changes neither `BladeburnerRank` nor `BladeburnerSkillCost`: the theme
  node leaves its own feature at BN1 rates. BN7 does not
  ([`bn07.md`](bn07.md)).
- Completing every black operation ends the BitNode with no Red Pill and no
  hacking level, in any node where the division is accessible — not a BN6
  special case. See [`../features/bladeburner.md`](../features/bladeburner.md).
