# BN12 — The Recursion

> *"Repeat."* · theme: `progression`

**In-node:** nothing, and everything. SF12 has **no maximum level**; each
completion raises it by one and makes the node compoundingly harder. It is the
node *about* the reset loop, which is why `progression` owns it.

## Multipliers vs BN1

Every field is a function of the SF12 level `lvl`:

```
inc = 1.02 ^ lvl        dec = 1 / inc
```

| Group | Changes |
|---|---|
| Skills | all six `*LevelMultiplier` = `dec` |
| Experience | all five `*ExpGain` = `dec` |
| Servers | `ServerGrowthRate`, `ServerStartingMoney`, `ServerWeakenRate` = `dec` · `ServerMaxMoney` = `dec²` · **`ServerStartingSecurity` = 1.5 fixed** |
| Fleet | `HomeComputerRamCost`, `CloudServerCost`, `CloudServerSoftcap` = `inc` · `CloudServerLimit`, `CloudServerMaxRam` = `dec` |
| Income | `CompanyWorkMoney`, `CrimeMoney`, `HacknetNodeMoney`, `ManualHackMoney`, `ScriptHackMoney`, `CodingContractMoney`, `DarknetMoneyMultiplier` = `dec` |
| Reputation | `FactionPassiveRepGain`, `FactionWorkRepGain` = `dec` · `FavorToDonateToFaction` = `inc` |
| Reset loop | `AugmentationMoneyCost`, `AugmentationRepCost` = `inc` · `DaedalusAugsRequirement` = `floor(min(30 + inc, 40))` |
| Market | `FourSigmaMarketDataCost`, `FourSigmaMarketDataApiCost` = `inc` · `InfiltrationMoney`, `InfiltrationRep` = `dec` |
| Other features | `CorporationValuation`, `BladeburnerRank`, `GangUniqueAugs` = `dec` · `BladeburnerSkillCost` = `inc` · `StaneksGiftPowerMultiplier`, `StaneksGiftExtraSize` = `inc` · **`CorporationSoftcap` 0.8, `CorporationDivisions` 0.5, `GangSoftcap` 0.8 — all fixed** |
| Endgame | `WorldDaemonDifficulty` = `inc` |

## Reading

- At `lvl = 0` every `inc`/`dec` is exactly 1, so a first BN12 run is BN1 plus
  four fixed nerfs (`ServerStartingSecurity` 1.5, corp 0.8 / 0.5, gang 0.8).
- Stanek is the one thing that gets **better** the deeper you recurse
  (`StaneksGiftExtraSize` is additive, so `inc` there is a size bonus).
- Because difficulty is a single smooth integer axis, BN12 is the **ideal
  benchmark for our own efficiency** — run the same controller at successive
  SF12 levels and the only variable is known exactly. Better A/B substrate than
  comparing differently-shaped nodes.

## SF12

Start any BitNode with **NeuroFlux Governor equal to the SF12 level**. No cap.
NFG levels count toward `numAugmentations`, so a high SF12 also shortens the
path to Daedalus everywhere.

## For our code

- `progression` must **derive** the multipliers from SF12 level. A per-node
  table of constants would be wrong here.
- BN12 is the natural home for a controller-efficiency simulator suite: same
  goal, sweep `lvl`, plot time-to-goal.
