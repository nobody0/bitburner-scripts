# BN1 — Source Genesis

BN1 is the unmodified baseline. Its BitNode multipliers are all defaults, so
strategies tuned here must be rechecked in other BitNodes.

## SF1

SF1 starts every new BitNode with **32 GB home RAM** and applies these permanent
player multipliers:

| Level | Total bonus | Gain from prior level |
|---|---:|---:|
| SF1.1 | +16% (×1.16) | +16 points |
| SF1.2 | +24% (×1.24) | +8 points |
| SF1.3 | +28% (×1.28) | +4 points |

These are totals, not bonuses that stack with one another. SF1 improves
hacking, skills and XP, company/faction reputation, crime, work income, and
Hacknet production. Hacknet node purchase and upgrade costs receive the inverse
multiplier; SF1.3 therefore applies 1 / 1.28 = 0.78125. See BitNode.tsx and
SourceFile/applySourceFile.ts in the pinned game source.

## Finish

1. Own **The Red Pill** (Daedalus: 2,500,000 rep, $0).
2. **Install** it. Buying it is insufficient; installation adds
   w0r1d_d43m0n to the network (Prestige.ts:175).
3. Regrow to hacking **3000**, open five ports, root w0r1d_d43m0n, and finish.
   The Cave on the path requires hacking 925.

The scheduling trap is step 2: installation resets hacking to 1. Plan the final
augmentation batch and the post-install regrow together.

Daedalus requires **30 installed augmentation objects**, **$100b**, and either
hacking 2500 or all four combat stats at 1500 (FactionTable.ts). NeuroFlux
counts as one object regardless of stacked levels.

The Singularity finish needs hacking 3000 and admin rights; it installs the
backdoor itself (NetscriptFunctions/Singularity.ts:1170). The terminal route
requires a manual backdoor.

Alternative finishes:

- All 20 Bladeburner black operations bypass The Red Pill and hacking
  requirements; see [bn06.md](bn06.md).
- With SF15, the darknet labyrinth can award The Red Pill without Daedalus
  (DarkNet/effects/labyrinth.ts:424).

## Availability

A first-ever BN1 has no Source-Files, so the reset loop is partly manual.
Returning runs depend on carried Source-Files:

| Capability | Requirement |
|---|---|
| hacking, Hacknet, side work, progression, Go | always |
| stock | buy WSE + TIX, or SF8 |
| automated factions and career | SF4 |
| gang | SF2 and karma ≤ −54,000 |
| corporation / Bladeburner / sleeves / Stanek / darknet | SF3 / SF6 or SF7 / SF10 / SF13 / SF15 |

A **cold BN1** should automate what it can and report manual steps. A
**returning BN1** with SF4 can be fully automated.

## Route

1. Scan, root, deploy, and farm. Buy TOR and port openers early.
2. Follow CyberSec → NiteSec → The Black Hand → BitRunners.
3. Add factions and NeuroFlux only when they improve the route to 30 augs.
4. Balance augmentation batches against ×1.9 queued-augmentation price
   escalation and rep-to-favor conversion.
5. Install The Red Pill with the final hacking batch, regrow to 3000, finish.

Faction rep resets on install and becomes permanent favor. Donations unlock at
150 favor and cost $1m per base reputation. Money, skills, jobs, purchased
servers, kills, memberships, and ordinary programs reset; karma, favor, home
RAM, and cores persist.

## For our code

- progression must model the Red Pill install and regrow as a phase.
- progression must optimize augmentation batch size, not merely spend all cash.
- factions must model persistent favor, per-install rep, and the 150-favor
  donation threshold.
- career must distinguish per-install kills from per-node karma.
- Cold BN1 must report manual steps instead of waiting forever for SF4 APIs.
- The simulator goal needs Daedalus (30 augs, $100b, hacking 2500), Red Pill
  installation, and the final hacking-3000 regrow.
