# BN15 — The Secrets of the Dark Net

> *"The rules have changed"* · theme: `dnet`

**In-node:** the darknet — a constantly shifting network where servers move or
disappear, long-distance communication is unreliable, and scripts must be
"self-sufficient and durable, and spread themselves to stay alive". Access comes
from weak passwords and leaky logs.

**The headline rule:** *"In this BitNode, the Daedalus faction has not yet found
and monopolized the fabled Red Pill augmentation."* The Red Pill is out in the
dark instead — see the labyrinth, below.

**What the node is for.** Its own description states the objective plainly:
*"If you can take advantage of the darknet servers' weak passwords and leaky
logs, you will be able to gain access to the deepest parts of the darknet and its
secrets."* Destroying it grants SF15, or upgrades an existing SF15 to a maximum
of level 3. So the node is a password-and-traversal problem: reach depth by
cracking servers, under a network that rearranges itself while you work.

The mechanic itself — the `ns.dnet` API, network shape, mutation clock, server
models, passwords, caches, darknet RAM, and our remote-execution model — is in
[`spec/dnet.md`](../../dnet.md). This note is the node: its multipliers, its
source file, and what is specific to playing BN15.

## Multipliers vs BN1

| Group | Changes |
|---|---|
| Hacking | `HackingLevelMultiplier` 0.6 · `HackingSpeedMultiplier` **0.6** · `ScriptHackMoney` **unchanged** |
| Skills | all four combat 0.7 · **`CharismaLevelMultiplier` 1.1** |
| Servers | `ServerMaxMoney` 0.8 · `ServerStartingMoney` 0.5 · `ServerStartingSecurity` 1.5 |
| Reset loop | `AugmentationMoneyCost` 3 · **`DaedalusAugsRequirement` 20** |
| Other features | `CorporationValuation` 0.2 · `CorporationSoftcap` 0.4 · `CorporationDivisions` 0.4 · `BladeburnerRank` 0.2 · `BladeburnerSkillCost` 3 · `GangUniqueAugs` 0.3 · `StaneksGiftPowerMultiplier` 0.7 · `StaneksGiftExtraSize` −2 |
| Endgame | `WorldDaemonDifficulty` 2 → hacking 6000 |

`DarknetMoneyMultiplier` is **1** here, which is worth stating because it is not
elsewhere: BN3 0.4, BN4 0.4, BN5 0.7, **BN8 0**, BN9 0.05, BN10 0.4, BN13 0.1,
and BN12 scales it by SF12 level. Darknet income is node-dependent, so `dnet` is
a money source in some nodes and none at all in others.

**BN15's mutation clock.** The clock's `rateMultiplier` is 1 in BN15 and 2
everywhere else — the one node-specific term in the formula. At the
pre-labyrinth depth of 5 that is a mutation tick every **6 seconds** here and 12
elsewhere; the full clock is in `spec/dnet.md` and
`shared/strategy/dnet/rates.ts`.

## Reading

- **`CharismaLevelMultiplier: 1.1` is the only stat buff in any BitNode.** The
  charisma that matters most is the **labyrinth ladder** —
  `LABYRINTH_CHARISMA = [300, 600, 1500, 2500, 3000, 3500, 4000]`
  (`shared/strategy/progression/endgame.ts`), seven gates for six rewards plus
  The Red Pill. SF15's own levels also scale off charisma. So `career` → `dnet`
  for charisma is a real edge — but see the cycle: `dnet` partly pays its own
  charisma bill through `phishingAttack()` and the labyrinth augmentations.
- `ScriptHackMoney` is untouched and `ServerMaxMoney` only 0.8 — **BN15 does not
  force you off the farm.** It is one of the mildest nodes for ordinary hacking.
- `DaedalusAugsRequirement: 20` is the lowest in the game.

## The labyrinth — a second Red Pill

The labyrinth's reward engine — the six-augmentation prereq chain, their
`charisma` and `dnet_money` multipliers, the stasis-limit growth — is a mechanic
and lives in `spec/dnet.md`. What is node-dependent is where The Red Pill sits:

- **In BN15**, The Red Pill replaces **The L4w of Bayes** in the sequence, so
  four rewards precede it rather than six.
- **In any other node where `DarknetLabyrinthRewardsTheRedPill ≠ 0`**, The Red
  Pill comes after all six.
- The multiplier **defaults to 1**, and only **BN8** sets it to 0.

So the labyrinth is a Red Pill route in **thirteen of fifteen BitNodes**, not a
BN15 curiosity — and since SF15.1 unlocks the full dark web everywhere, it is a
genuine alternative to Daedalus's 2 500 000 rep. That has direct consequences
for [`bn01.md`](bn01.md).

## SF15

| Level | Effect |
|---|---|
| 1 | Permanently start with the **TOR router and DarkScape**, and unlock the full dark web in all BitNodes |
| 2 | Charisma raises **job salary and rep gain**. The API docs also attribute "+20% authentication speed" here, but the code gates that on `activeSourceFileLvl(15) > 2` (`DarkNet/effects/effects.ts:80-83`) — the discount is **level 3**; code wins, the doc is wrong upstream |
| 3 | Charisma raises **faction work rep gain**; +50% xp and money from `.cache` files; the auth-speed discount above |

SF15.1 is the structurally interesting one: TOR permanently removes the
$200 000 early-game gate on port openers in *every* node, and full dark web
access is what makes the labyrinth route portable.

SF15.3's reputation effect is precise and transcribable
(`PersonObjects/formulas/Reputation.ts`): at level 3 and above, charisma is
added to the faction-work rate at **0.1×** for hacking work and **0.3×** for
security and field work. In field work that bonus is scaled by the share bonus
and charisma already counts at 1× separately; in security work it is not scaled.

Note that our capability gate is broader than SF15: darknet access is BN15, an
active SF15, **or** `DarkscapeNavigator.exe` on home
(`shared/features/unlock.ts`). The `.exe` path is not source-file gated.

## For our code

- `dnet` needs a `needs`-board edge to `career` for **charisma**, driven by the
  labyrinth ladder rather than by `getServerRequiredCharismaLevel`. It is not a
  one-way edge: `phishingAttack()` builds charisma, so `dnet` feeds back.
- `progression` should know the labyrinth exists as an alternative Red Pill
  route once SF15 is held.
- The first hop is free, darknet RAM is a separate pool, and the
  remote-execution model with the rules that follow from it are all in
  [`spec/dnet.md`](../../dnet.md).
