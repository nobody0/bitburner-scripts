# BN15 — The Secrets of the Dark Net

> *"The rules have changed"* · theme: `dnet`

**In-node:** the darknet — a constantly shifting network where servers move or
disappear, long-distance communication is unreliable, and scripts must be
"self-sufficient and durable, and spread themselves to stay alive". Access comes
from weak passwords and leaky logs.

**The headline rule:** *"In this BitNode, the Daedalus faction has not yet found
and monopolized the fabled Red Pill augmentation."* The Red Pill is out in the
dark instead — see the labyrinth, below.

## Reading

- **`CharismaLevelMultiplier: 1.1` is the only stat buff in any BitNode.**
  Charisma gates darknet targets (`dnet.getServerRequiredCharismaLevel`) and
  SF15's own levels scale off it. `career` → `dnet` for charisma is a real edge,
  and the only place charisma matters outside company promotions.
- `ScriptHackMoney` is untouched and `ServerMaxMoney` only 0.8 — **BN15 does not
  force you off the farm.** It is one of the mildest nodes for ordinary hacking.
- `DaedalusAugsRequirement: 20` is the lowest in the game.

## The labyrinth — a second Red Pill

`DarkNet/effects/labyrinth.ts` awards a fixed augmentation sequence: The Broken
Wings → The Boots → The Hammer → The Staff → The Law → The Sword. Then:

- **In BN15**, The Red Pill replaces **The Law** in that sequence.
- **In any other node where `DarknetLabyrinthRewardsTheRedPill ≠ 0`**, The Red
  Pill comes after all six.
- The multiplier **defaults to 1**, and only **BN8** sets it to 0.

So the labyrinth is a Red Pill route in **thirteen of fifteen BitNodes**, not a
BN15 curiosity — and since SF15.1 unlocks the full dark web everywhere, it is a
genuine alternative to Daedalus's 2 500 000 rep. That has direct consequences
for [`bn01.md`](bn01.md).

## The `ns.dnet` surface

| Call | Role |
|---|---|
| `probe()`, `getServerDetails`, `getDepth`, `isDarknetServer`, `getServerRequiredCharismaLevel` | Enumerate and select targets |
| `authenticate(host, password)` / `connectToSession(host, password)` | Access — the first needs a direct connection, the second does not |
| `heartbleed(host, options)` | The capture action; threaded, priced by `formulas.dnet.getHeartbleedTime` |
| `openCache(filename)` | Retrieve captured data |
| `memoryReallocation()`, `getBlockedRam()` | Free RAM held by the server owner's processes — darknet servers are a **fleet resource** |
| `setStasisLink()`, `getStasisLinkLimit()`, `getStasisLinkedServers()` | Pin servers against migration; the limit makes links scarce |
| `induceServerMigration(host)` | Force a server to move |
| `unleashStormSeed()`, `getDarknetInstability()`, `nextMutation()` | The instability clock that rotates the map |
| `promoteStock(sym)` | A direct `stock` interaction |
| `phishingAttack()`, `labreport()`, `labradar()` | Labyrinth and support actions |

## SF15

| Level | Effect |
|---|---|
| 1 | Permanently start with the **TOR router and DarkScape**, and unlock the full dark web in all BitNodes |
| 2 | Charisma raises **job salary and rep gain**; +20% authentication speed |
| 3 | Charisma raises **faction work rep gain**; +50% xp and money from `.cache` files |

SF15.1 is the structurally interesting one: TOR permanently removes the
$200 000 early-game gate on port openers in *every* node, and full dark web
access is what makes the labyrinth route portable.

## For our code

- `dnet` needs a `needs`-board edge to `career` for **charisma** — the first
  dependency of that shape.
- If `memoryReallocation` yields fleet RAM, the heap gains a host class with its
  own lifetime (servers migrate away). That is an architectural change, not a
  driver.
- `progression` should know the labyrinth exists as an alternative Red Pill
  route once SF15 is held.
