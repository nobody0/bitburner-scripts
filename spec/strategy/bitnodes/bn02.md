# BN2 — Rise of the Underworld

> *"From the shadows, they rose"* · theme: [`gang`](../features/gang.md)

**In-node:** `canAccessGang()` returns `{ success: true }` on `bitNodeN === 2`
before it tests SF2 or karma, so a gang needs neither here
(`src/PersonObjects/Player/PlayerObjectGangMethods.ts:12-30`; only
`bitNodeOptions.disableGang` still refuses, `:13-15`). Seven factions can found
one — Slum Snakes, Tetrads, The Syndicate, The Dark Army, Speakers for the Dead,
NiteSec, The Black Hand (`GangConstants.Names`, `src/Gang/data/Constants.ts:18-26`).
**The Red Pill is added to a gang faction's catalogue only when `bitNodeN === 2`**
(`src/Faction/FactionHelpers.tsx:180-183`). Bare `src/…` paths are the pinned
`v3.0.1` tag — source 3 in [`README`](../README.md) — because `src/Gang/` and
`src/Faction/FactionHelpers.tsx` are outside the vendor extract
(`tools/vendor.ts:40,72`).

## SF2

Gangs in other BitNodes once karma ≤ **−54 000**
(`GangConstants.GangKarmaRequirement`, `src/Gang/data/Constants.ts:27`).
Crime success rate, crime money and charisma multipliers gain **+24% / 36% /
42%** at levels 1 / 2 / 3 — `Σ 24/2^i` over the levels held, applied to
`crime_success`, `crime_money` and `charisma`
(`sim/vendor/bitburner/src/SourceFile/applySourceFile.ts:49-60`). The
`sfDescription` text and the applied code agree
(`src/BitNode/BitNode.tsx:92-102`).

## Notes

- `CloudServerSoftcap` **rises** to 1.3, and higher is worse
  (`shared/features/bitnode.ts:449`, `harderWhen: HIGHER`) — purchased-server
  cost scaling is nerfed, not relaxed.
- BN2 is the only node that doubles `StaneksGiftPowerMultiplier` while
  shrinking the grid; BN13's 2× comes with `StaneksGiftExtraSize` +1
  ([`stanek`](../features/stanek.md)).
