# BN14 — IPvGO Subnet Takeover

> *"Territory exists only in the 'net"* · theme: `go`

**In-node:** nothing gated. **IPvGO is playable in every BitNode with no
Source-File** — what BN14 changes is that Go is *worth* playing (`GoPower: 4`).
Winning subnets grants node power (stat multipliers) and faction favor.
`go.cheat` is separate, and needs SF14.2.

## Reading

- Faction **and** company rep gain both at 0.2× turns the normal rep engine off.
  Go's faction favor is the substitute — which is exactly why SF14 raises the
  favor you can win from IPvGO.
- `HackingSpeedMultiplier: 0.3` is shared only with BN15 and is the one that
  hits **our batching** hardest: every HWGW timing stretches and spacer windows
  change. A schedule computed at 1× mis-times every operation here.
- `CrimeSuccessRate: 0.4` is unique to BN14 and quietly wrecks the karma engine
  — Homicide's effective karma/second drops with it.

## SF14

| Level | Effect |
|---|---|
| 1 | +100% stat multipliers from node Power |
| 2 | Permanently unlocks the `go.cheat` API |
| 3 | +25% additive success rate for `go.cheat` |

Also raises the **maximum favor from winstreaks per faction** to a 200k / 300k /
400k rep equivalent, and the **rep converted to favor for two consecutive wins**
to 1000 / 1500 / 2000.

## Node power, and which opponent to farm

`Go/effects/effect.ts`:

```
effect = 1 + ln(nodes + 1) * (nodes + 1)^0.3 * 0.002
           * bonusPower * GoPower * (SF14 held ? 2 : 1)
```

`nodes` is that **opponent's** accumulated node power, so the bonuses are
per-opponent and independent — and each opponent grants a *different*
multiplier (`Go/Constants.ts`):

| Opponent | `bonusPower` | Grants |
|---|---|---|
| w0r1d_d43m0n | **2.0** | hacking **level** |
| Netburners | 1.3 | hacknet production |
| Slum Snakes | 1.2 | crime success rate |
| Daedalus | 1.1 | company **and** faction reputation |
| The Black Hand | 0.9 | hacking money |
| Tetrads | 0.7 | strength, defense, dexterity, agility |
| Illuminati | 0.7 | `hacking_speed` |

Two of these matter far beyond BN14. **Daedalus** is a faction-rep multiplier
that no reset touches, and **Illuminati** is `hacking_speed` — the one player
multiplier that directly offsets `HackingSpeedMultiplier`. Since Go costs no
work slot and no Source-File, both are close to free income for `factions` and
`hacking` in *every* node.

Winstreak favor is capped at a 100 000 rep equivalent, raised to
200k / 300k / 400k by SF14 level.

## For our code

- `go` needs an opponent-aware playing strategy, and — separately — an
  **opponent-selection** strategy, because the seven bonuses are not
  interchangeable. That choice is worth more than play strength early.
- The dispatcher must read `HackingSpeedMultiplier`.
