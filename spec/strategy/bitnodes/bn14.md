# BN14 — IPvGO Subnet Takeover

> *"Territory exists only in the 'net"* · theme: `go`

**In-node:** nothing gated. **IPvGO is playable in every BitNode with no
Source-File** — what BN14 changes is that Go is *worth* playing (`GoPower: 4`).
Winning subnets grants node power (stat multipliers) and faction favor.
`go.cheat` is separate, and needs SF14.2.

## Reading

- Faction **and** company rep gain both at 0.2× turns the normal rep engine off.
  Go's faction favor is the substitute — which is exactly why SF14 raises the
  favor you can win from IPvGO.
- `HackingSpeedMultiplier: 0.3` is shared only with BN15 and is the one that
  hits **our batching** hardest: every HWGW timing stretches and spacer windows
  change. A schedule computed at 1× mis-times every operation here.
- `CrimeSuccessRate: 0.4` is unique to BN14 and quietly wrecks the karma engine
  — Homicide's effective karma/second drops with it.

## Node power, and which opponent to farm

`Go/effects/effect.ts`:

```
effect = 1 + ln(nodes + 1) * (nodes + 1)^0.3 * 0.002
           * bonusPower * GoPower * (SF14 held ? 2 : 1)
```

`nodes` is that **opponent's** accumulated node power, so the bonuses are
per-opponent and independent — and each opponent grants a *different*
multiplier (`Go/Constants.ts`):

| Opponent | `bonusPower` | Grants |
|---|---|---|
| w0r1d_d43m0n | **2.0** | hacking **level** |
| Netburners | 1.3 | hacknet production |
| Slum Snakes | 1.2 | crime success rate |
| Daedalus | 1.1 | company **and** faction reputation |
| The Black Hand | 0.9 | hacking money |
| Tetrads | 0.7 | strength, defense, dexterity, agility |
| Illuminati | 0.7 | `hacking_speed` |

Two of these matter far beyond BN14. **Daedalus** is a faction-rep multiplier
that no reset touches, and **Illuminati** is `hacking_speed` — the one player
multiplier that directly offsets `HackingSpeedMultiplier`. Since Go costs no
work slot and no Source-File, both are close to free income for `factions` and
`hacking` in *every* node.

Winstreak favor is capped at a 100 000 rep equivalent, raised to
200k / 300k / 400k by SF14 level.

### Exact cost and payout mechanics (v3.0.1)

Go spends no money and does not occupy `Player.currentWork`. Its real costs are
wall time and dodge RAM: `makeMove` / `getBoardState` are 4 GB,
`analysis.getValidMoves` is 8 GB, and the chain/liberty/territory analysis calls
are 16 GB. The zero-cost calls include pass, reset, game state, opponent,
history and stats. A normal AI response consumes at least two waits; asynchronous
move-option probes can add several more. Each wait is 200 ms, or 40 ms while
offline bonus cycles remain, which is why small boards dominate reward per
wall-clock second.

Black's final score is routers plus surrounded empty nodes. White gets the same
plus komi. A tie counts as a player win. Every completed game adds black score
to the opponent's node count and adds this node power:

```
blackScore * difficulty(komi, boardSize) * streakMultiplier
```

`difficulty` is `(komi + 0.5) / 4`, except 5x5 Illuminati is deliberately 8x.
The streak multiplier is 1.0 through 3.0 for wins, 0.5 during a losing streak,
and up to 5x when breaking a dry streak. Every second consecutive win against
a faction we have joined converts `maxRep / 200` through the game's nonlinear
`addRepToFavor` formula (until that opponent's Go rep counter reaches the
SF14-dependent cap). The strategy prices the resulting favor-rate multiplier
against remaining work for that faction; it does not treat the grant as normal
faction reputation. This makes board
size, current streak, faction membership and the *kind* of multiplier needed
part of opponent selection; current bonus percentage alone is not a value
function.

### RNG: what is and is not safely predictable

Both the AI and cheats construct the same Wichmann–Hill generator from
`Player.totalPlaytime`. Reimplementing that published behavior is fair strategy:
our four-draw stream is bit-identical to the pinned `WHRNG` over fractional and
wrapped seeds. The live driver reads public playtime inside the dodge, performs
the cheap seed-dependent finalization, verifies that playtime is still in the
same slot, and immediately calls Go. At normal speed the AI's first 200 ms wait
therefore gives one exact next-cycle seed. A 40 ms bonus wait can straddle the
unknown engine phase, so that honest forecast retains only the current and next
cycle. An observed engine rollover anchors the tick phase. Within 20 ms of the
next rollover, the driver forecasts for that next tick and waits out the short
remainder; an unexpected rollover triggers one warm replan against the tick
actually in force.

The faction predictor is a clean-room implementation of the AI's observable
board analysis, pattern vocabulary, option ordering and faction priority tree;
it does not import vendored code in production. One upstream defend tie-break
uses unseeded `Math.random()`, so the predictor returns the complete possible
reply set for that case rather than pretending to know a value the public state
cannot determine. Simulator tests import the pinned v3.0.1 implementation only
as an oracle and require exact reply containment across every faction,
5/7/9/13 boards, generated offline-node layouts and reachable histories. They
also pin the exact two-choice defense case at several `Math.random()` values.

The live move planner rates legal moves plus pass with a trained value network,
after applying each retained candidate and its predicted faction reply. The
19x19 board caps that set; 5x5 evaluates it in full. Selection is by predicted
win probability, with terminal Power per round breaking exact ties. See
`spec/go-ai.md`.

## For our code

- Use a rules-correct column-major board engine (capture, suicide and positional
  superko). Legality, scoring and the reply model stay exact and handwritten;
  only the position *valuation* is learned.
- Keep **opponent selection** separate from move selection. Attribute the
  install/node ETA components to money, crime, combat, reputation, hacknet,
  hacking speed and hacking level, then rank expected seconds saved per game
  second. Preserve streaks and price an odd joined-faction streak as a one-win
  favor event; other states require the measured continuation cost of two wins.
- Play 5x5 for wall-time throughput. It is also uniquely rewarded 8x against
  Illuminati.
- Split the essential 4 GB board probe from the optional 16 GB territory probe.
  Bundling them prevents Go from playing on the hardware where its “free”
  background value matters most.
- Use the parity-proven WHRNG and sampled playtime to forecast each retained
  candidate's immediate reply, and dispatch inside the engine cycle that
  forecast assumes: near a rollover, target the next cycle and wait for it.
- Await the response promise already returned by `makeMove`/`passTurn`, then
  raise a one-shot scheduler wake for the controller's immediate catch-up pass.
  There is no polling delay between resolved turns. Use
  `opponentNextTurn(false, false)` only to reattach when a restart finds White
  already thinking; calling it after an awaited move would duplicate the same
  promise rather than make the opponent faster.
- Keep the production rules handcrafted. Differential tests import the pinned
  v3.0.1 board engine only from `sim/vendor`, sweep reachable positions, and
  compare legality, captures, liberties, superko and scoring to detect drift.
- Measure strength only against the imported pinned faction AI on stratified
  seed corpora. Synthetic baselines are not evidence, and a promoted model is
  only promoted if it wins more complete games than the incumbent.
- The dispatcher must read `HackingSpeedMultiplier`.
